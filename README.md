# Bali 2026 · app móvil v5

Versión preparada para GitHub Pages.

## Archivos
- `index.html` — app
- `manifest.webmanifest` — instalación como app
- `sw.js` — caché/offline
- `icon.svg` — icono

## Publicación
Sube **los cuatro archivos a la raíz** del repositorio. Después activa GitHub Pages desde `main` / `(root)`.

La app funciona sin librerías externas. Los enlaces de navegación abren Google Maps.
